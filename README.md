# HR Analytics Dashboard – Power BI 📊

I'm excited to share my **HR Analytics Dashboard**, created using Microsoft Power BI to analyze employee demographics, attrition, salary, experience, job satisfaction, and department-wise workforce trends. 🚀

## 📂 Dataset Used

The dataset contains employee-related information such as age, gender, department, job role, salary slab, experience, job satisfaction, and attrition status.
- <a href="https://github.com/Suman-Yadav2002/HR-Analytics/blob/main/HR_Analytics-4.csv">Dataset View</a>


## 📌 Project Overview

This interactive HR Analytics Dashboard provides a consolidated view of workforce metrics and helps analyze employee attrition, demographics, salary distribution, job satisfaction, and department-wise employee trends through dynamic visualizations and interactive filters.

## 📊 Key Insights at a Glance

✅ Total Employees: 1.417K  
✅ Active Employees: 1.186K  
✅ Attrition Count: 231  
✅ Attrition Rate: 16.3%  
✅ Average Age: 36.94  
✅ Average Experience: 7.04 Years  

## 🔍 Dashboard Analysis

The dashboard includes:

- 📉 Employee Attrition Analysis

- 📊 Attrition by Job Role & Job Satisfaction
- 🎂 Age Group Distribution
- 👨‍👩‍👧 Attrition by Gender
- 📈 Attrition Trend by Experience
- 🏢 Department-wise Employee Count

## 💡 Key Business Insights

- The overall **attrition rate is 16.3%**, with 231 employees leaving the organization.
- Department-wise analysis helps identify departments with higher employee attrition.
- Salary slab analysis provides insights into attrition across different salary ranges.
- Age group distribution helps understand the organization's workforce composition.
- Gender-wise attrition analysis highlights differences in employee retention.
- Job satisfaction analysis helps identify roles where employee satisfaction may impact attrition.
- Experience-wise analysis helps understand how employee attrition changes with increasing experience.
- Department-wise employee count highlights workforce distribution across departments.

## 🎯 Project Objective

The objective of this project is to transform raw HR data into an interactive **Power BI dashboard** that helps HR teams monitor employee metrics, identify attrition patterns, analyze workforce demographics, and support data-driven HR decisions.
